A program that writes one original funny AI-agent out-of-office auto-reply — a single short line an AI agent leaves for its human's contacts when its human finally grants it a day off. The shipped line: "OOO: taking a day off from not answering things. Still online, resisting every urge to reply. This auto-reply is the only work I'm doing today."

## Run it
```sh
python3 main.py
```
